# 第二阶段：Qt Quick 对照学习

更新：2026-09-17。依据用户新要求，取消“必须独立手写UI”的约束。目的是能对代码讲清关键部分，可由AI实现、解释和帮助修改。

## 实施范围

复用core、adapters、数据集和测试口径，重做QML展示、输入及渲染层；不复用Widgets控件。先完成Widgets可讲解闭环，再实施Quick。

| 任务 | 实现主题 | 学习成果 |
|---|---|---|
| Q01 | QML窗口、布局、模型绑定 | 解释属性绑定与C++状态同步 |
| Q02 | 缩放、平移、选区 | 对照Widgets事件处理与QML输入 |
| Q03 | QQuickItem批量几何与LOD | 解释GUI/渲染线程和资源生命周期 |
| Q04 | 热力图、资源曲线、详情联动 | 说明哪些业务复用、哪些UI重写 |
| Q05 | 性能测量、打包、对照复盘 | 用相同数据回答QPainter与Scene Graph取舍 |

可先用QQuickPaintedItem探索迁移，再根据实测选择场景图实现；不预设Quick一定比Widgets快。[QQuickItem文档](https://doc.qt.io/qt-6/qquickitem.html)

共享契约：稳定eventId、选择/视口分离、精确统计不依赖LOD、渲染只消费有界批次、不可变数据跨线程。不能对百万事件创建百万QML delegate。

## 验收

同一数据、视口、操作序列下，统计和导出一致；分别测量CPU、内存与输入响应，注明测量边界。作者能够对着代码讲出架构、渲染路径和至少一个真实问题的定位过程。练习可用口述、调参、调试或局部修改，不要求重复手写全部代码。
