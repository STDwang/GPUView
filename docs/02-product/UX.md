# 界面与交互规范

版本：v1.0｜目标交互规范；时间线基础交互已实现，其余以README状态为准

## 当前已实现的交互增量

轨道导航支持勾选、名称过滤和CPU/GPU组折叠；折叠组也从时间轴与统计中隐藏。名称区滚轮滚动轨道，事件区滚轮缩放。轨道竖向滚动条位于时间轴右侧、详情栏左侧，各侧栏滚动条统一明暗样式。

点击事件以金色边框和轨道底色高亮，详情页显示原始记录；框选切换统计页，在后台计算。工具栏可缩放到选区或返回上一视图（最多64条历史）。时间刻度随缩放调整秒/毫秒/微秒与精度；悬停提示时间和概览桶计数。

真实帧模式额外展示帧间隔曲线；统计页选择单个进程/交换链并可双击长帧定位，来源页持续保留质量警告。学习说明独立于选择结果。关闭辅助侧栏后从“视图”菜单恢复。

下方线框是完整产品目标，尚未实现的热力图、导出、名称聚合、回放等不能当作现有功能。

## 主窗口线框

```text
┌ 文件/视图/分析/帮助 ─ 打开 ─ 导出 ─ 重置布局 ──────────────┐
│ 会话名  来源/真实或模拟  进程/交换链  时间单位  数据质量      │
├────────────┬──────────────────────────┬──────────────┤
│ 数据源/轨道│ 全局概览与当前视口         │ 当前事件详情 │
│ 筛选条件   ├──────────────────────────┤ 原始字段     │
│ 折叠/显示  │ 多轨时间线 / 帧时间曲线    │ 缺失与来源   │
│            ├──────────────────────────┤              │
│            │ 热力图 / 资源曲线         │              │
├────────────┴──────────────────────────┴──────────────┤
│ 统计摘要 | 事件明细 | 名称聚合(B) | 导入警告 | 性能诊断(B) │
├───────────────────────────────────────────────────────┤
│ 加载/就绪/回放  数据量  选区 [开始,结束)  进度/取消        │
└───────────────────────────────────────────────────────┘
```

以 QMainWindow、QDockWidget、QSplitter 组织；主时间轴始终保留足够空间。低分辨率隐藏辅助面板，可通过菜单恢复。颜色用于类别/强度，不单独承担状态表达；选中项同时使用边框和文字。

## 时间线交互

| 动作 | 行为 |
|---|---|
| 滚轮 | 时间缩放，以鼠标所指时间为锚点，夹紧到会话范围 |
| 中键拖动或空格+左键拖动 | 时间平移 |
| 左键点击 | 选择事件并联动详情；同像素密集事件进入局部放大或候选列表 |
| 左键拖动 | 框选时间，松开后异步计算统计 |
| 双击事件 | 使事件适配视口，保留边缘余量 |
| Esc | 清除选区/取消当前拖拽，不取消后台导入 |
| Home / 工具栏“全览” | 重置视口到全范围 |
| Ctrl+O / Ctrl+E | 打开 / 导出；导出在无数据时禁用 |

视口与分析选区是两个独立状态：缩放只改变看到什么，框选才改变统计什么。无选区时统计当前过滤后的整个会话。零宽拖拽按点击处理，避免除零。跨轨选择的时间范围保持一致。

## 联动与数据质量

- 点击热力图定位对应时间桶；点击表格行用 eventId 定位；过滤后选中事件不可见时提示并清除选择。
- 更新统计时显示“计算中”，不得把旧统计贴上新范围标签。加载取消返回旧会话。
- 没有 GPU Busy、功耗或显存字段时对应视图显示“数据源未提供”，不画零线。
- PresentMon 模式显示帧与指标轨道；不能把一个 GPU Busy 数值画成有确切起止位置的真实 GPU 执行片段。
- 合成 Trace 顶部持续显示“教学模拟数据”；来源标识写入导出报告。
- 资源面板显示“整卡遥测，约 xxx ms 采样间隔”；对齐不确定时展示偏移及误差标记。
- 每条曲线自己的量纲和坐标轴可见，百分比、毫秒、MiB 不共用一个无说明纵轴。

## 状态与错误

Empty → Loading → Ready；Loading 可到 Cancelling、Failed；Ready 可到 Loading、Replaying；Replaying 可到 Paused 或 Ready。状态由应用层统一管理。

空窗口提供“打开数据”和“打开内置示例”；示例分真实脱敏、教学模拟两类。文件损坏提供错误摘要和行号，路径不存在提供重选入口，格式未知提供支持字段说明。错误信息可复制，但不自动发送。

长加载支持取消；关闭窗口时先取消任务并等待安全退出，短时间未结束时显示退出进度，不强杀线程。后台查询失败保留当前视图并提供重试；数据不足时禁用不适用操作而不是弹连续错误框。
