## 验证与测量

Debug/Release均通过2个CTest套件、52个实际用例（Core 42 + UI 10；Qt总数44 + 12包含初始化和清理）。新增模型契约、排序身份、热力图联动、输入摘要、导出转义/空值、中途取消保留旧文件、冻结快照和输入覆盖保护。

Release合成百万帧分析中位数764.882ms、模型重置1.8442ms、首次离屏表格绘制1.4415ms。每规模预热1轮后3次实测；不能推断屏幕FPS或P95。[原始证据](../../benchmarks/reports/FRAME_ANALYSIS.md)。外部CSV解析器复核公开样本完整导出905个唯一ID、排序、SHA与多行备注。帧页面截图已更新并目视检查。

## 限制与下一步

- 固定60FPS长帧预算；未支持Dropped筛选、1% Low、其他PresentMon字段版本自动适配。
- Present间隔不是GPU执行时长或实际显示FPS；样本来自主动制造长帧的受控目标。
- 完整A验收仍缺干净环境部署；B仍缺资源遥测、多源集成、Trace文件解析、回放；Quick对照未开始。时钟映射仅算法验证。
- 当前排序会重算统计/热力图，可在测量证明必要后复用；没有连续排序输入延迟或断电恢复验证。
- 用户尚未完成口述与修改练习，不推断掌握程度。

下一步优先：干净环境发布包与可复现启动检查，再处理目标FPS/数据筛选等分析口径；不重复实现现有导入/表格/导出。
