# 十个面试问题：代码与证据索引

来源：用户于2026-09-17直接提供的问题原文。本表随实现更新，不能把规划中的代码写成现有能力。

| ID | 原题 | 负责模块 | 必需证据 |
|---|---|---|---|
| Q01 | 如何在Qt中流畅显示百万级事件？ | core索引、渲染数据批次、TimelineWidget | 百万数据加载/查询/绘制测量 |
| Q02 | 为什么不能给每个事件创建一个QGraphicsItem/QML Item？ | 紧凑事件存储、自绘Widget | 对象规模与渲染图元统计；说明不是绝对禁止 |

| Q04 | 如何减少高频信号导致的事件队列堆积？ | 会话控制器、最新请求合并 | 有界待办、迟到结果拒绝测试 |

| Q07 | QPainter、QGraphicsView、Qt Quick Scene Graph如何选择？ | Widgets绘制、后续Quick对照 | 场景/成本/限制；没有对照实测不宣称更快 |
| Q08 | 什么情况下做缓存，缓存如何失效？ | RenderCache、版本化键 | 相同请求命中、数据/视口/尺寸变化失效测试 |

每题最终采用：遇到的问题 → 复现步骤 → 失败方案 → 解决思路 → 具体函数与短代码 → 测试/测量 → 30秒口述 → 追问与边界。开发中由 CASEBOOK.md 持续记录，不等开发结束后凭空编造经历。
